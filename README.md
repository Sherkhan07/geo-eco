# Геоэкологиялық зерттеу платформасы

7–11-сыныптарға арналған геоэкологиялық зерттеу платформасының тұжырымдамасы мен интерактивті сайты.

## Не бар

- **3D макет**: мектеп ауласының айналатын макеті, онда 8 тақырып өз орнында белгіленген. «Жылу картасы» режимі оқушының өз өлшемдерінен құрылады.
- **Менің геоэкологиялық зерттеуім**: зерттеу жолы, температура өлшемдерінің кестесі мен диаграммасы, 9 қадамнан тұратын жоба паспорты (мәтінді көшіруге болады).
- **Деректер зертханасы**: су есептегіш күнделігі, сынып қалдықтары, жарықтандыру шығыны (кВт·сағ), мектептің жасыл паспорты (ағаш картасы), көлік санағышы.
- Платформа бөлімдері, сыныптарға бейімдеу, жобалар банкі, бағалау және алғашқы нұсқа.

## Іске қосу

`index.html` файлын браузерде ашыңыз. 3D кітапхана (three.js) мен шрифттер интернеттен жүктеледі.

Оқушы енгізген деректер тек сол браузерде (`localStorage`) сақталады.
